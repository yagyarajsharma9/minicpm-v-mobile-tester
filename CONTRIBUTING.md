# Contributing to MiniCPM-V 4.6 Mobile Tester

Thank you for your interest in contributing! This project is a local testing tool for OpenBMB MiniCPM-V 4.6 with a FastAPI web interface (Python) and an Android APK build (Kotlin + llama.cpp JNI).

## How to Contribute

### Reporting Issues
- Use GitHub Issues to report bugs, request features, or ask questions.
- Include your OS, Python version, and steps to reproduce for bugs.

### Submitting Changes
1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/your-feature`).
3. Make your changes.
4. Add or update tests if applicable.
5. Commit with a clear message.
6. Push to your fork and open a Pull Request.

### Code Style
- Python: follow PEP 8 conventions. Use descriptive variable names.
- Kotlin: follow Android Kotlin style conventions.
- Shell scripts: include comments for non-obvious steps.

### Pull Request Process
1. Ensure your code passes any existing self-tests.
2. Update the README if your change affects setup or usage.
3. Link any related issues in your PR description.
4. Wait for maintainer review before merging.

## Areas for Contribution
- Additional LLM provider support
- Mobile UI improvements
- New self-test scripts
- Android feature expansion
- Documentation and examples

## Questions?
Open a GitHub Discussion or an Issue — we welcome all questions.
